# Hamburg Grid

Hamburg Regional Command, a regional resilience and scenario-planning exercise for the Hamburg metropolitan region, in a single HTML file.

**Live app:** https://mfmadinaveitia1-del.github.io/hamburg-grid/

## What it does

- Simulates a mixed drone and cruise-missile attack on Hamburg-area infrastructure and a layered response (radar, SAM launchers, interceptor drones, gun trucks, jammers, nets).
- **Attack:** any number of drones, four drone types, cruise missiles with an optional warhead, start time, direction and aim.
- **Defence:** three preset sets or a custom set with layers on/off, unit counts and positions on a map.
- **Timeline:** extra waves, blasts and timed response actions; defence stations take damage and the defence weakens over time.
- Overview, Aerial, Street and 3D city views of the same simulation.

## Important

All scenarios, locations, detections, costs and outcomes are synthetic and illustrative. This is a training and planning exercise, not live intelligence or operational guidance. Blast effect radii use simplified textbook scaling and are approximate.

## Running it

Open `index.html` in a browser, or use the live link above. Map imagery, 3D tiles and fonts load from external services, so an internet connection is needed for the full view.
